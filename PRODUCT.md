# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users
- Developers and engineering teams in Cambodia integrating online payments.
- Startups and merchants looking for easy ABA PayWay and KHQR payment setup.
- Engineers using modern runtimes (Next.js, Node.js, Bun, Deno, Cloudflare Workers).

## Product Purpose
Provide simple, reliable, and practical documentation for `aba-payway-sdk-unofficial` so developers can integrate ABA PayWay and KHQR quickly without confusion.

## Positioning
The unofficial, zero-dependency, edge-ready TypeScript SDK that simplifies ABA PayWay API with complete type safety and automatic cryptographic hashing.

## Operating Context
- Developers browsing documentation and copying quickstart code snippets.
- Interactive testing with ABA Sandbox and checking transaction status.
- Mobile payment flow via KHQR scanning and ABA Mobile deeplinks.

## Capabilities and Constraints
- Full guides for Setup, Purchase API, Check Status, KHQR, Webhooks, Deeplink, and Testing.
- Built with Next.js 15 App Router, React 19, Fumadocs, and Tailwind CSS.
- Community project: unofficial and independent from ABA Bank.

## Brand Commitments
- Visual identity: Cambodian Royal Blue, Cyan highlights, and modern dark theme.
- Voice: Clear, simple, developer-friendly, and concise.

## Evidence on Hand
- Documentation pages in `content/docs/`.
- Interactive hero demo component on homepage (`components/landing-hero-demo.tsx`).
- Community Telegram channels and GitHub repository.

## Product Principles
- Simple and actionable: short explanations with ready-to-use code.
- Cryptographic safety: correct HMAC-SHA512 signing by default.
- Edge-ready: zero extra dependencies, standard Web Crypto and fetch.
- Developer experience: strict TypeScript types and easy copyable snippets.

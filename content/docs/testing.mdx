Testing against the live ABA PayWay Sandbox requires understanding how the sandbox environment behaves differently from production.

<Callout title="Important Sandbox Limitation: KHQR" type="warn">
<strong>Sandbox KHQR cannot be scanned by the real ABA Mobile app.</strong>

Transactions created with <code>abapay_khqr</code> stay <code>PENDING</code> forever because real banking apps cannot process test Bakong QR strings. <strong>Hosted card checkout is the only sandbox flow a human can actually complete.</strong>
</Callout>

---

## ABA Test Cards

You cannot use real credit cards in the sandbox. Use these test cards:

| Card Status | Card Type | Card Number | Exp | CVV | 3DS Enrolled | Note |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **Success** | Mastercard | `5156 8399 3770 6777` | 01/30 | 993 | No | **Recommended first test** — no OTP required. |
| **Success** | Visa | `4286 0900 0000 0206` | 04/30 | 777 | Yes | Sends OTP to registered ABA account email. |
| **Declined** | Mastercard | `5156 8302 7256 1029` | 04/30 | 777 | Yes | Declined with OTP step. |
| **Declined** | Visa | `4156 8399 3770 6777` | 01/30 | 993 | No | Declined without OTP. |

<Callout title="180-Second Hosted Page Timeout" type="info">
The hosted checkout page's token expires <strong>180 seconds</strong> after creation. Complete test card entry promptly once the page opens.
</Callout>

## SDK Testing CLI Tools

The SDK includes dedicated scripts to verify sandbox behavior:

```bash
# 1. Drive one payment end-to-end (creates purchase, opens browser, polls to APPROVED)
npm run pay:sandbox

# 2. Generate a dated evidence report to submit to ABA when requesting production access
npm run report:sandbox

# 3. Verify credentials before testing
npm run verify:credentials

# 4. View raw KHQR code image
npm run see:qr
```

## Setup Environment File

Create a `.env` file in the root repository directory:

```bash
ABA_MERCHANT_ID=your_sandbox_merchant_id
ABA_API_KEY=your_sandbox_api_key
ABA_BASE_URL=https://checkout-sandbox.payway.com.kh
```

---

## Running Test Suites

Run the mocked unit test suite:

```bash
npm test
```

Run live sandbox integration tests:

```bash
npm run test:sandbox
```

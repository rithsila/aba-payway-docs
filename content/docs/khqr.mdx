---
title: KHQR Generation
description: Generating customized SVG KHQR payment cards
---

Generate branded, self-contained SVG cards embedding the EMV QR string:

```typescript
import { generateKHQR } from "aba-payway-sdk-unofficial";

const svgDataUri = await generateKHQR({
  emvData: purchase.qrString!, // from createPurchase()
  amount: 25.00,
  currency: "USD",
  merchantName: "My Shop Cambodia",
  headerColor: "#0057b8", // Custom header banner color — defaults to official KHQR red
});

// Returns: "data:image/svg+xml;base64,PHN2ZyB4bWxucz0..."
```

This is what the card looks like — a red header (matching the official KHQR
branding, including its diagonal "flag tail" corner), the amount, a
"Scan • Pay • Done" tagline, and a viewfinder-style corner frame around the
QR itself:

## Official Reference & Guidelines

- **ABA Official KHQR Guidelines**: [https://developer.payway.com.kh/khqr-guideline-3192101f0](https://developer.payway.com.kh/khqr-guideline-3192101f0)
- **ABA QR API Specification**: [https://developer.payway.com.kh/aba-qr-api-3158158f0](https://developer.payway.com.kh/aba-qr-api-3158158f0)
- **National Bank of Cambodia (NBC Bakong API Docs)**: [https://api-bakong.nbc.gov.kh/document](https://api-bakong.nbc.gov.kh/document)

## Render in HTML or React

You can pass the returned Data URI directly to any standard `<img>` tag:

```jsx
<img
  src={svgDataUri}
  alt="Scan to pay with KHQR"
  className="w-full max-w-sm rounded-xl shadow-lg"
/>
```

---

## Options (`KHQROptions`)

| Option | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `emvData` | `string` | Yes | EMV QR data string from ABA API. |
| `amount` | `number` | Yes | Amount shown on the QR card. |
| `currency` | `"USD" \| "KHR"` | Yes | Currency code. |
| `merchantName` | `string` | Yes | Merchant name displayed in card header. |
| `headerColor` | `string` | No | Header hex/CSS color (default: `#bc271a`, the official KHQR red). |

---
title: Checking Status
description: Polling and querying transaction payment state
---

Query the status of any transaction using `checkStatus()`:

```typescript
const response = await aba.checkStatus("TXN_1740001");

if (response.success) {
  console.log("Status:", response.status);
  console.log("Paid Amount:", response.amount);
  console.log("Payment Time:", response.paymentTime);
} else {
  console.error(`Query failed (code ${response.errorCode}):`, response.error);
}
```

<Callout title="Good to know" type="info">
Before a customer pays, `amount` is set but `currency` stays empty — ABA
only fills that in once money has actually moved. A brand-new transaction
can also briefly report "not found" (code `6`) for about a second right
after you create it — this isn't a bug, ABA just needs a moment to make it
queryable. Retry once or twice if you see this right after `createPurchase()`.
</Callout>

## Possible Payment Statuses

This is the complete list `response.status` can be — there are no others:

| Status | Description |
| :--- | :--- |
| `APPROVED` | Payment completed successfully. |
| `PENDING` | Awaiting customer action / payment. |
| `DECLINED` | Payment declined by card issuer or bank. |
| `REFUNDED` | Transaction was refunded. |
| `ERROR` | `response.success` is `false` — check `response.errorCode` and `response.error` for why (e.g. `6` = transaction not found, `21` = expired API key). |
